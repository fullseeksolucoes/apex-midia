The decision

Optimizer + CSS placeholder — not a DB blur pipeline

  • Serve AVIF/WebP via Next's optimizer, cached 1 year. Biggest byte win with zero per-image work. Safe to cache forever because image URLs are content-unique (UploadThing mints a new key per upload).
  • Fluency via a CSS ImageFrame that reserves the exact aspect box (zero layout shift) and shows a subtle cream shimmer behind opaque photos.
  • Rejected for now: true per-image blurDataURL LQIP — nicer blur-up, but needs a Prisma column + backfill. Deferred as its own reviewed migration (noted in MEMORY.md).
What changed

Five areas that matter

  • next.config.ts — AVIF+WebP formats, minimumCacheTTL 1yr, qualities [75,82], allowlist *.vimeocdn.com / i.ytimg.com.
  • components/media/ImageFrame.tsx + app/globals.css — new LQIP frame + prefers-reduced-motion-aware shimmer.
  • ProjectGrid / ProjectGallery / SelectedWork / RelatedProjects / AboutGalleryLayouts — photos wrapped in ImageFrame; gallery at quality={82}.
  • components/media/VideoPlayer.tsx — posters drop unoptimized, go through the optimizer.
  • public/ — hero banners recompressed 3.5 MB → ~200 KB; deleted 4 unreferenced banner files.
How it was verified

Green gate + adversarial review

  • reviewer: approve Separate agent tried to refute 7 ways — no blockers. Confirmed placeholder tone is cream (not dark), no aspectRatio: NaN path, quality allowlist complete, poster hosts covered.
  • Build / typecheck / lint — green. tsc --noEmit clean, next build generated all 30 routes, lint clean on every touched file.
  • Measured live — curl against next start: hero returns Content-Type: image/avif, 68 KB, Cache-Control: max-age=31536000; WebP fallback for non-AVIF browsers.
  • Hero banner recompression visually checked — crisp logos, no banding on gradients.
Risk / watch-out

Two things to keep an eye on

  • 1-year cache assumes content-unique URLs. If a future flow ever reuses a stable URL for changed image content, it could serve stale for a year — lower minimumCacheTTL if that ever happens.
  • Vimeo poster host. Broadened to *.vimeocdn.com; if an optimized poster ever renders broken, confirm its host is covered in remotePatterns.
  • Next win: real blurDataURL blur-up for an even more premium feel — deferred, tracked in MEMORY.md.
